# Post-Labor Economics

A first-principles investigation of one question:

> Once AI automates mental and physical labor entirely, what happens to our economy?

This repository holds the research notes, quantitative models, figures, and the
manuscript for a guide that builds its answer step by step, from axioms about
what an economy is to concrete scenarios for 2026–2036 and a final best guess.

**Status:** work in progress. The finished guide will be published as a PDF in
[`dist/`](dist/).

## Layout

| Path | Contents |
| --- | --- |
| `research/` | Sourced research notes on theory, data, history, and policy |
| `data/` | Public data series used in figures |
| `models/` | Small, transparent models and the scripts that produce the figures |
| `figures/` | Generated figures |
| `manuscript/` | Source of the guide |
| `dist/` | The compiled PDF |
